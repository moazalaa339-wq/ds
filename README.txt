Hawa Engine v2.3+
================

تشغيل
-----
1) دوس مرتين: START_SERVER.bat
2) سيّب النافذة السودا مفتوحة
3) المتصفح يفتح صفحة البناء مرة واحدة
4) زر «فتح اللعبة» أو OPEN_GAME.bat = نفس السيرفر

إيقاف / مسح من Task Manager
---------------------------
- اقفل نافذة START_SERVER (X أو Ctrl+C)
  → السيرفر يتقفل ويتنضف لوحده
- أو دوس: STOP_SERVER.bat
  → يقتل العملية من Task Manager ويمسح ملفات القفل
- بعد كده تقدر تحذف المجلد عادي

ملفات
-----
START_SERVER.bat  تشغيل
STOP_SERVER.bat   إيقاف وتنظيف
OPEN_GAME.bat     فتح اللعبة
http_server.py    السيرفر

  style = "abaya" للعباءة أو "armor" للشكل المدرّع الأصلي.

تعديل v2.9 — مايك صوتي + اهتزاز متزامن
--------------------------------------
- زر مايك أسفل يمين في وضع اللعب (أيقونة خضراء/حمراء + حرف B).
- مفتاح B أو الضغط بالماوس يفعّل/يوقف المايك.
- الاهتزاز (فم + رأس) يظهر فقط عند وجود صوت فعلي، مش مجرد مايك مفتوح، ويتزامن مع اللاعبين الآخرين.
- الصوت الحقيقي يُرسل عبر PeerJS (نداء media) وفي LAN عبر WebRTC tracks.
- التحكم من قسم البرمجة / الكائنات البرمجية / الملف التلقائي:
  game.voice.set({ sensitivity, maxMouth, headShake, headShakeEnabled,
                   smoothing, highpass, lowpass, noiseGate, shape, gain, enabled })
  game.voice.get() / toggle() / isOn() / level()
- shape: "natural" أو "cartoon" — شكل فتح الفم.
- headShakeEnabled: false يمنع اهتزاز الرأس مع الإبقاء على الفم.

- مراجعة أزرار: جديد / رفع / تلقائي / تعديل / تفعيل / حذف — مع حماية null وإجبار نوع الـ id.

تعديل v2.15 — إصلاح الركوب (اللاعب كان بيتحشر في الكرسي)
---------------------------------------------------------
السبب: origin اللاعب عند القدمين، والسكربتات كانت بتحطه على نقطة الكرسي فالحوض بيغرق ~0.57م جوّه المخدة،
والـ AI كان بيخمّن أبعاد الشخصية (ومفيش أي رقم حقيقي في الملف التلقائي).
الحل:
- Game.getPlayerDims(0) → أبعاد اللاعب الحقيقية متقاسة من الهيكل نفسه: stand / ride / sit
  (الطول، ارتفاع الحوض، فخذ، ساق، ذراع، عرض الكتف، الراس فوق الكرسي، القدم تحت الكرسي، إزاحة الجلوس).
- Game.seatPlayer(0, x, y, z, {yaw, scale, lift, pose}) → (x,y,z) = أعلى سطح المخدة. بتخصم إزاحة الجلوس الحقيقية،
  وتظبط الحجم، وتثني الركبتين. pose:'none' للموتوسيكل/الحصان (بتظبط الأرجل بنفسك).
- Game.unseatPlayer(0, x, y, z) → ينزّل اللاعب ويرجّع الحجم والأرجل.
- Game.getRideScale() / setRideScale(s) لتغيير حجم الراكب العام.
- الأونلاين: الحجم والأرجل بيتبعتوا، فاللاعب التاني بيشوفك قاعد صح (كان بيتحط +0.55 فوق المركبة بوضع واقف).
- الملف التلقائي (برمجة + كائنات برمجية) بقى فيه قسم «أبعاد اللاعب الحقيقية + الركوب والجلوس» بالأرقام الفعلية
  وقواعد تصميم الكرسي/الكابينة على قد اللاعب، وقاعدة جديدة في OUTPUT_RULES.
- samples/tuktuk_realistic.js و samples/motorcycle.js بيقيسوا اللاعب من المحرك (fitRider) بدل أرقام ثابتة قديمة.
- بتشتغل في الشكل الخفيف كمان: game.seatPlayer(x,y,z,opt) / game.getPlayerDims() / game.unseatPlayer().

التخزين التلقائي:
- المشروع بيتحفظ لوحده في مكان ثابت على الجهاز: <مجلد المستخدم>/HawaEngineData/project (بيتكتب في نافذة السيرفر السودا).
- مفيش اختيار مجلد تاني ولا «حدد مكان التخزين». بيشتغل على الكمبيوتر والموبايل.
- المكان برّه مجلد المحرك وغير مربوط بالبورت أو المتصفح: لو بعت المحرك لحد، أو حدّثت نسخته، مشروعه بيفتح هو هو.
- مشروعك القديم (اللي كان في مجلد اخترته): أول مرة بيطلب إذن قراءة وينقله للتخزين التلقائي مرة واحدة.
  لو رفضت: «عرض التخزين» ← «استيراد من المجلد القديم».
- لو غيّرت المكان: متغير البيئة HAWA_DATA قبل تشغيل السيرفر.
- لو السيرفر مش شغال (فتح index.html مباشرة)، بيرجع لاختيار المجلد زي الأول.
- لمشاركة مشروعك مع حد: زر تحميل المشروع ZIP (مش مجلد التخزين).

البناء:
- المحور اللي ماسكه (سهم/حلقة/مربع) بينوّر أصفر، والمحاور التانية بتخفت لحد ما تسيبه — لمس وماوس.
- الوضع في أي مكان: الكائن بيتحط بالظبط على السطح اللي عليه المؤشر، حتى لو ملزوق أو جنب كائن تاني (مفيش «المكان مشغول» ولا زحزحة).
  لسه بيلزق في السطح اللي بيلمسه ومبيدخلش فيه.
- موبايل: الجويستيك بإصبع + إصبع تاني على المشهد = تدوير كاميرا (كان بيعمل زووم). الزووم بإصبعين على المشهد لسه شغال.
